# 创新药合作里程碑

这是一个面向“创新药共同开发”运营协作的服务端项目。服务把领域记录、负责人和当前状态保存到本地 SQLite，应用层通过进程内请求适配器提供健康检查和基础登记能力，业务流程在这个边界上运行。

## 能力

- **版本化登记**：项目、适应症、地区权利、里程碑、证据均为追加式版本表，历史不可改；区域拆分把原权利标记为 superseded 并登记新权利的责任方。
- **双方提交、指定角色确认**：任一方可提交里程碑证据，必须由对方持有项目确认角色（默认 `jsc`）的人确认；确认可撤销，撤销会抽走达成依据。
- **撤回冻结**：证据被撤回（或确认撤销导致达成依据消失）时，同一适应症链上序号更靠后的里程碑一律冻结，需指定角色显式解冻。
- **付款只能冲正**：付款请求需对方财务角色确认，确认时把所用证据版本与审批链固化为决定快照；已确认的付款不能删除，只能冲正（reversal）并保留抵销记录。
- **结论不随时间漂移**：截止日在登记时归一到 UTC，证据是否在截止日内只在提交时判定一次；付款请求与网关回调按幂等键记录，重试原样返回首次结论。
- **决定可还原**：`payment_decision` 还原每笔付款的证据版本、确认人、审批链与后续事件；`audit_trail` 可按实体回放全部动作。

## 目录

- `src/drug_pipeline/domain.py` 定义记录对象、角色、状态机和 UTC 时间处理。
- `src/drug_pipeline/store.py` 负责 SQLite 连接、表结构和记录读写，写操作由事务统一提交。
- `src/drug_pipeline/service.py` 提供应用服务入口（登记、确认、冻结、付款、查询）。
- `src/drug_pipeline/api.py` 将 JSON 请求转换为服务调用，业务错误返回结构化 `error`。
- `tests/` 保存领域边界的可重复测试，`test_collaboration.py` 为验收演练。

## 运行

运行测试：`PYTHONPATH=src python3 -m unittest discover -s tests`

检查源码：`python3 -m compileall src`

项目只使用 Python 标准库，测试和运行不需要启动其他服务。

## 验收演练

`tests/test_collaboration.py` 覆盖：双方并行提交证据、部分达成与限额付款、
区域拆分与责任方查询、确认撤销后冻结与冲正、证据撤回冻结、跨时区截止日判定、
崩溃重启恢复与回调重试、付款决定还原。
